# Customer Churn Prediction Using Logistic Regression

## 📌 Project Overview

This project uses Logistic Regression to predict customer churn.

## 🎯 Objective

The objective is to predict whether a customer will churn based on:
- Age
- Monthly Charges
- Tenure
- Support Calls

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- Scikit-learn
- Seaborn

## 📊 Dataset

The dataset contains 40 customer records and 6 columns.

## 🤖 Machine Learning Model

Logistic Regression was used for binary classification.

## 📈 Model Results

The model achieved an accuracy of **87.5%** on the test set.

The 5-fold cross-validation mean accuracy was **100%**.

## 📊 Visualization

A correlation heatmap was used to analyze relationships between numerical features.
